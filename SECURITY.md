# Bezbednost

Ako nađeš bezbednosni problem (npr. način da neko drugi pošalje komandu trackeru preko aplikacije
ili da pročita poruke), **nemoj otvarati javni Issue**. Prijavi ga privatno:
repo → kartica *Security* → **Report a vulnerability**.

Odgovor obično stiže u roku od nekoliko dana. Podržana je samo poslednja objavljena verzija.

---

**English:** Please report security issues privately via *Security → Report a vulnerability*,
not as a public issue. Only the latest release is supported.
